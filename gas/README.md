# Google Apps Script (GAS) 校園抽獎後端設定指引

本目錄包含活動抽獎系統專用的 Google Apps Script 後端腳本 `Code.gs`。透過此腳本，可將 Google 試算表（Google Form 學生報名表單回應與獎品分頁）發布為無伺服器的唯讀 JSON Web App API，完全免除後端伺服器架設與維護成本。

---

## 1. Google 試算表分頁結構與 Demo 資料 (可直接複製貼上)

請在您的 Google 試算表中建立以下兩個工作表分頁（或由 Google 表單自動產生試算表後新增第二個分頁）：

---

### 📋 分頁一：學生抽獎名單

* **分頁名稱**：`表單回應 1`（若使用 Google Form 連結試算表，此為系統預設名稱；亦相容 `表單回應`、`參加名單`、`名冊`、`Form Responses 1`）
* **欄位結構**：
  1. `時間戳記`（Google 表單自動產生）
  2. `系所`（必填，支援「系所」、「學系」、「系級」、「科系」）
  3. `年級`（必填，如：大一、大二、大三、大四、碩一、碩二）
  4. `姓名`（必填，學生真實姓名）
  5. `學號`（選填，作為防止同名同姓的識別序號）
  6. `電子郵件`（選填，中獎通知聯絡用）
  7. `手機號碼`（選填，沒有學號者的替代識別資料；僅接受台灣手機）
  8. `活動識別碼`（選填，主辦單位發放的報到序號／號碼牌）
  9. `系統識別碼`（**由系統自動產生，請勿手動填寫或修改**；首次載入時若不存在會自動建立於最右側）

#### 🪪 參加者身分識別規則

系統依下列優先序，取第一個有填寫的資料作為參加者的識別依據：

| 優先序 | 識別資料 | 說明 |
| :---: | :--- | :--- |
| 1 | 學號 | 忽略大小寫、全形與空白，例如 `b11902001 ` 與 `B11902001` 視為相同 |
| 2 | 活動識別碼 | 同上 |
| 3 | 手機號碼 | 統一為 `09xxxxxxxx`；`0912-345-678`、`+886 912 345 678`、被試算表吃掉前導 0 的 `912345678` 皆視為相同 |
| 4 | 系統識別碼 | 三者皆未填時使用，照常參加抽獎 |

* **姓名不作為識別依據**，同名不同人會被視為不同參加者，舞台上以 `#學號`、`#活動碼`、`☎ 0912-***-678` 或 `#系統碼` 區分。
* **重複報名**（同一識別資料且同姓名）：自動合併為最早送出的一筆。
* **同一學號／活動識別碼但姓名不同**：保留最早送出的一筆，其餘暫時排除，並於前端「名單識別提醒」顯示列號，請修正試算表後重新載入。
* **同一手機、不同姓名**（家人共用、代填）：視為不同人，並標示「共用號碼」。
* **疑似重複**（同姓名＋系所＋年級但識別資料不同，或同手機且姓名只差一字）：只提醒，不自動合併。
* `無`、`沒有`、`N/A`、`-`、`0` 等填寫內容視為未填。
* 中獎紀錄同時記錄識別資料與系統識別碼，因此名單重新排序、刪列、新增，或中獎者事後補填學號，都不會造成中獎紀錄錯置或重複中獎。

> [!IMPORTANT]
> **隱私**：API 不回傳完整手機號碼，只回傳遮罩值（如 `0912-***-678`）與加鹽雜湊後的識別鍵。中獎後若需聯絡，請以匯出 CSV 中的「系統識別碼」回試算表查詢完整號碼。電子郵件仍以原值回傳，若有疑慮請勿收集。

#### 📝 Google 表單「手機號碼」欄位設定建議
* 題型：**簡答**，選填。
* 點選右下角「⋮」→ **回應驗證** → **規則運算式** → **符合**，填入：
  ```text
  ^(\+?886-?|0)?9\d{2}[-\s]?\d{3}[-\s]?\d{3}$
  ```
* 錯誤訊息：`請輸入台灣手機號碼，例如 0912-345-678`

### 🎁 分頁二：獎品設定

* **分頁名稱**：請命名為 `獎品設定`（亦相容 `獎品`、`獎品清單`、`獎項`、`Prizes`）
* **欄位結構**：
  1. `獎品名稱`（必填，如：特獎、頭獎等）
  2. `配額`（必填，正整數，該獎項的名額總數）
  3. `抽獎順序`（選填，正整數，數字越小越先抽出，如 1, 2, 3）
  4. `備註`（選填，獎品詳細規格說明）
  5. `獎品代碼`（選填，獎品的固定代碼，如 `P01`；未填時以獎品名稱識別。若有兩個同名獎項，請填寫不同代碼）

> 獎品以「獎品代碼」或「獎品名稱」識別，與列的順序無關，調整分頁排序不會影響已抽出的中獎紀錄。**活動進行中請勿修改獎品名稱或代碼**。

## 2. 部署 Google Apps Script 步驟

1. **開啟 Google 試算表**：開啟已貼妥上述分頁與資料的 Google 試算表。
2. **開啟 Apps Script 編輯器**：點選試算表上方選單的 **擴充功能 (Extensions)** -> **Apps Script**。
3. **貼上後端程式碼**：將編輯器中的預設內容全部清空，貼上本目錄下的 [`Code.gs`]
4. **儲存專案**：點擊上方磁碟片圖示或按 `Ctrl + S` 儲存。
5. **執行一次性設定函式**（編輯器上方函式下拉選單選取後按「執行」，首次需授權試算表編輯權限）：
   - `setupPhoneSalt`：建立手機號碼雜湊用的秘密鹽（存於指令碼屬性 `PHONE_SALT`）。⚠️ **活動期間切勿刪除或更換**，否則既有中獎紀錄將無法對應。
   - `setupTriggers`：安裝表單送出觸發器，並為既有資料列補上「系統識別碼」。
   - （可選）`testIdentityFixtures`：執行身分識別情境測試，紀錄中顯示「全部通過」即正常。
   - 建議將「系統識別碼」欄設為**保護範圍**（資料 → 保護工作表和範圍），避免被誤改。
6. **建立新部署**：
   - 點擊右上角藍色按鈕 **「部署 (Deploy)」** -> **「新增部署作業 (New deployment)」**。
   - 點選左側齒輪圖示，選擇 **「網路應用程式 (Web app)」**。
7. **設定部署參數（關鍵）**：
   - **說明 (Description)**：`校園抽獎系統 Web API`
   - **執行身分 (Execute as)**：`我 (Me / 您的 Google 帳號)`
   - **誰可以存取 (Who has access)**：**`所有人 (Anyone)`**  
     *(⚠️ 重要提醒：必須選為 Anyone，前端網頁才能免登入直接呼叫 API；若選錯會遭遇 CORS 錯誤)*
8. **授權權限**：
   - 點選 **「部署」**。首次執行時 Google 會跳出授權確認視窗。
   - 依序點選「審查權限」-> 選擇您的帳號 -> 點擊「進階 (Advanced)」-> 點擊「前往 (安全)」完成試算表授權（新版會寫入「系統識別碼」欄，需要編輯權限）。
9. **取得 API 網址**：
   - 部署完成後，複製畫面上顯示的 **網路應用程式網址 (Web app URL)**，格式如：
     ```text
     https://script.google.com/macros/s/AKfycb.../exec
     ```
10. **至前端網頁測試連線**：
   - 開啟抽獎系統前端首頁，點選右上角 **「⚙️ 設定 API」**，貼上此網址並點擊 **「連線載入資料」**，即可立即同步試算表名單與獎項！

> [!NOTE]
> **從舊版升級**：貼上新版 `Code.gs` 並完成步驟 5 後，請至 **部署 → 管理部署作業 → 編輯（鉛筆圖示）→ 版本選「新版本」→ 部署**，網址不變即可生效。舊版以列號產生的編號（`s_N`、`user_N`）已停用；瀏覽器中既有的中獎紀錄會自動轉換，無法對應者標示「舊版紀錄，請人工核對」。
